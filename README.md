# channel-course-brief

A brief for an AI assistant (or a person): find the subject for a YouTube channel whose whole catalogue is one
course — watch every video and you have mastered something deep and wide.

| File | What it is |
|---|---|
| [PROMPT.md](PROMPT.md) | The brief. Give it to the assistant as its whole prompt |
| [ANSWER.md](ANSWER.md) | Where the answer goes, in the structure the brief asks for |

To answer: edit `ANSWER.md` directly if you have write access, or fork this repository and open a pull request.
Keep the headings of the brief (Steps 1–5) so answers from different assistants can be compared side by side;
if more than one assistant answers, use one file each (`ANSWER-<name>.md`).
